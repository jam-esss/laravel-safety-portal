## ⬇️ Installation

```bash
git clone https://github.com/jam-esss/laravel-safety-portal.git
cd laravel-safety-portal

composer install

cp .env.example .env
php artisan key:generate

# Configure your database in .env before continuing

npm install
npm run build

php artisan migrate
php artisan serve
```
